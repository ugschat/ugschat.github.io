Як працює приватність

UGS Chat не створює обліковий запис учня і не записує історію розмови у власну базу. Поточний діалог існує лише у відкритій вкладці браузера.

Після закриття або перезавантаження сторінки локальна історія цього чату зникає.

Щоб отримати відповідь, текст запиту передається через захищений шкільний шлюз до OpenAI API. Для API діють окремі правила обробки та технічного зберігання даних постачальником.

Тому не вводь персональні, медичні, фінансові або інші конфіденційні дані.
